Какво е товаWhat this is

Python SDK за IPC CFX (Connected Factory Exchange) — отворения стандарт за комуникация между производствени машини и системи. SDK-то дава инструментите за вграждане на CFX протокола в Python приложения. A Python SDK for IPC CFX (Connected Factory Exchange) — the open standard for communication between manufacturing machines and systems. The SDK provides the tooling to embed the CFX protocol into Python applications.

  • AMQP 1.0 транспорт за съобщенияAMQP 1.0 messaging transport
  • обработка на CFX съобщения и нормализация JSON↔XMLCFX message handling and JSON↔XML normalisation
  • асинхронни операции и автоматично управление на връзкатаasynchronous operations and automatic connection management
  • HTTP forwarder към OdooHTTP forwarder to Odoo

  • RabbitMQ 4.x брокер (AMQP 1.0)broker (AMQP 1.0)

python-qpid-proton, pika и aio-pika не са runtime зависимости — Proton е вграден в rabbitmq-amqp-python-client. Кодът под src/server/examples/ е наследен демо материал и не се ползва от сървъра. python-qpid-proton, pika and aio-pika are not runtime dependencies — Proton is bundled inside rabbitmq-amqp-python-client. The code under src/server/examples/ is legacy demo material and is not used by the server.
